# PULSAR
Um pulsar é um fenômeno do cósmo, aonde ele ocorre quando uma estrela supermassiva explode em uma supernova. Essa explosão colossal faz com que a camada externa da estrela seja lançada para o espaço enquanto o seu núcleo está está colapsando consigo mesmo, resultado na criação de uma estrela de neutrons.
